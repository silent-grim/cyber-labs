# Cybersecurity Home Lab

This repository documents the design, setup, and maintenance of my personal cybersecurity laboratory used for hands-on experimentation, security research, and practical project development.

The lab serves as the foundation for all portfolio projects, providing a controlled environment for testing, analysis, and validation.
